 Communication Systems Simulations using MATLAB

This repository contains MATLAB implementations of fundamental analog and digital communication techniques developed as part of my Communication Systems coursework.

The programs demonstrate modulation, demodulation, signal analysis, and the effects of noise on communication signals.

📂 Topics Covered
1. Amplitude Modulation
->Double Sideband Full Carrier (DSB-FC)
->Double Sideband Suppressed Carrier (DSB-SC)
2. Amplitude Shift Keying (ASK)
->Binary Amplitude Shift Keying
->M-ary ASK (M = 4)
->M-ary ASK (M = 8)
3. Frequency Shift Keying (FSK)
->Binary Frequency Shift Keying
->FSK under Additive White Gaussian Noise (AWGN)
4. Phase Shift Keying (PSK)
->Binary Phase Shift Keying (BPSK)
->BPSK under Additive White Gaussian Noise (AWGN)
5. Frequency Modulation (FM)
->FM modulation
->FM demodulation
->FM using MATLAB built-in functions
->FM bandwidth analysis using Carson's Rule
6. Pulse Code Modulation (PCM)
->PCM signal generation and analysis
7. Delta Modulation
->Delta modulation
->Delta modulation in the presence of noise

🛠️ Tools Used
MATLAB

▶️ How to Run
Clone or download this repository.
Open MATLAB.
Navigate to the folder containing the required communication technique.
Open the corresponding .m file.
Run the script to observe the simulation output.
